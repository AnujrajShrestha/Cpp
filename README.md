A collection of my **C++ learning programs, practice exercises, and beginner projects**.

This repository is mainly focused on building a strong foundation in C++ by practicing core programming concepts through simple programs.

* Hello World & Basic Syntax
* Variables & Data Types
* Arrays
* Strings
* Pointers
* Functions
* Basic Problem Solving
* Mini Projects

## 🎮 Mini Projects

* **Number Guesser** — A simple number guessing game built using C++.

## 🛠️ Requirements

* C++ Compiler (GCC / MinGW)
* VS Code or any C++ compatible IDE

## ▶️ Compile & Run

```bash
g++ filename.cpp -o program
./program
```

On Windows:

```bash
g++ filename.cpp -o program.exe
program.exe
```
